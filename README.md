# 徐霞客旅行规划

一个中文旅行行程规划应用，支持目的地与多途经点路线、实时天气、DeepSeek 行程编排，以及 Tavily 地点资料检索。

## 功能

- 目的地、日期、天数、节奏与兴趣偏好设置
- 多途经点路线和分段交通方式
- 实时天气与逐日行程规划
- 未知途经点的 Tavily 检索与 DeepSeek 地区校核
- 经过校核的地点沉淀到所有访客共享的灵感景点库
- 动态灵感地点使用稳定且唯一的 SVG 配图
- AI 管家式排程：在人数、预算、交通与节奏条件内生成完整计划，摘要与每日排程同源
- 确定性规划管线：高德提供路线、坐标、POI、距离与导航事实，本地模块计算交通方式、门到门时间、每日容量、房间数和预算算术，Tavily 只补充非自驾交通价格与景点门票资料，DeepSeek 只在候选中选择、排序和分析
- 逐页流式路书：单页校验通过后再推送，页面事件带 runId、连续 index 和 checksum；全部页面通过后才能导出 PDF

## 开发

```bash
npm install
npm run dev
```

默认开发服务绑定 `0.0.0.0:8080`。

## 环境变量

部署时需要按平台配置：

- `BUTLER_PLANNER`：默认启用确定性 AI 管家链路；只有显式设置为 `0` 时才回退 legacy。设置为 `1` 或留空均走确定性管线。缺少 `DEEPSEEK_API_KEY` 或高德 Key 时 fail closed，不会用伪造的距离、时间或价格继续。
- `DEEPSEEK_API_KEY`：必需；用于候选景点选择、景点排序、分析与每日文案生成，不得用于覆盖本地时间或预算算术。
- `AMAP_WEB_SERVICE_KEY`：高德 Web 服务 Key，优先读取；也兼容 `AMAP_API_KEY` 或 `AMAP_KEY`。用于路线、坐标、POI、距离和导航。
- `TAVILY_API_KEY`：可选；只用于非自驾交通价格与景点门票资料检索。缺失时使用本地最低参考价或标记为参考价/兜底价。
- `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`、`TAVILY_SEARCH_URL`：可选的接口地址、模型和 Tavily 搜索端点覆盖项。
- `DATABASE_URL`：可选；持久化共享灵感景点，本地未配置时使用 PGlite 回退。

不要提交 `.env` 或任何密钥文件。

## 确定性规划管线

确定性路径的契约顺序如下，前序阶段通过或明确降级后才启动后序阶段：

```text
route -> pois -> selection -> timeline -> prices -> budget -> narrative -> pages
```

- `route`：高德负责路线、坐标和距离；本地决定交通方式与门到门时间。长距离通用偏好默认飞机，用户明确选择驾车或火车时尊重用户选择。
- `pois`：高德返回候选 POI 并过滤非景点；候选不足时只能使用带来源的本地兜底，不能由模型虚构景点。
- `selection`：DeepSeek 只能从候选 ID 中选择并排序；越界提案最多修复一次，仍失败则停止时间轴和预算阶段。
- `timeline`：本地先扣除通勤、换乘、用餐、入住和休息，再安排景点；单日容量不足时降级为周边休息或自由活动。
- `prices`：Tavily 查询非自驾交通价格与门票资料；缺失资料时使用本地最低价或参考价，不把估算写成已核验价。
- `budget`：交通按单人价 × 人数 × leg 数，住宿按房间数 × 晚数，餐饮按人数 × 天数，门票按成人/儿童/统一票类别计算，其他费用为 `max(200, 前四项 × 10%)`；五类预算按整数分摊到对应每日节点，余数进入最后一个分配节点，保证每日合计等于预算总额。
- `narrative`：每日生成、每日校验；失败日使用经过校验的本地安全文案，不阻塞其他日期。
- `pages`：只有校验后的页面才能进入预览。每个事件携带 `runId`、从 0 连续递增的 `index` 和 `checksum`；旧 run、乱序和重复页面会被丢弃。

价格置信度分为 `verified`（有明确来源且可作为已核验价）、`reference`（检索得到的参考区间）和 `fallback`（本地公式或最低价兜底）。预算上限是约束，不是必须花完的目标。

预览和 PDF 共用同一套每日文案校验与降级步骤。PDF 导出超过总预算时会改为安全可打印 HTML；超时兜底会移除地图、导航和历史引用，并重新校验文案。

当前单日文案缓存按最终排程内容哈希复用，最多保留 300 条；阶段级持久化缓存尚未作为已实现能力。确定性管线已是默认路径，只有 `BUTLER_PLANNER=0` 才回退 legacy；必要阶段失败时 fail closed，结果页只显示错误或配置提示，不挂载本地兜底路书，也不允许导出 PDF。

## 验收重点

- 北京到四川、5 人、5 天往返应默认选择飞机，交通费用按 5 人和往返 leg 累加。
- 非移动日必须包含真实候选景点，且通勤时间已从每日容量扣除。
- 路线地图首尾目的地完整可见，缩放不裁切。
- 路书预览固定高度、内部滚动、无双滚动条且不自动跳页。
- 预览与 PDF 使用同一份校验后文案和降级结果。
